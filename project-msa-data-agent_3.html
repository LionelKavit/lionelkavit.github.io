The problem

Data everyone has. Context no one can find.

MSA's Dynamics 365 ERP had evolved faster than its documentation. Columns had been renamed and repurposed with no record of what they meant, business logic lived in a few people's heads, and the manual data dictionary fell behind every schema change. Analysts burned hours on trial-and-error queries — and updating the docs always lost out to billable work.

How it works

Five tools. One seamless pipeline.

Everything runs inside MSA's existing Microsoft 365 stack — no new vendors, no new training. Fabric pipelines extract SQL metadata from Dynamics 365 on a daily schedule and upsert it into a SharePoint data dictionary, while a Copilot Studio agent lets anyone look up or update business definitions in plain language from Teams or Outlook — with Power Automate writing validated changes back in real time. And every AI-generated definition passes through human review before it's saved: the agent drafts, a person decides.

Reflection
Behind the build

The hard part wasn't the pipeline — it was getting busy professionals to contribute to documentation without it feeling like a burden, and the answer was to make it a conversation inside the tools they already use. The prototype ran on synthesized ERP data, and the occasionally generic AI definitions confirmed that human review stays essential. The best AI tools don't replace human judgment. They make it easier to express, capture, and preserve it.
